# The One-Year Question

Part of xiaojiahaina's neo-slow media framework. Before committing real
effort to something, ask:

> **"If someone engages with this well, every week, for one year — how are
> they different at the end of that year?"**

If the answer is only "they saved some time" — it's useful. Ship it if
useful is enough for the context.

If the answer is "they think differently, work differently, or feel
differently about something that matters to them" — it's worth the deeper
investment.

This single question is often the fastest way to separate a real idea from a
plausible-sounding one that would just add to the noise.
